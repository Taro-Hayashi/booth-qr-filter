# プライバシーポリシー

本拡張機能（以下、「当ソフトウェア」）におけるユーザー情報の取り扱い方針について説明します。

## 1. データの収集・送信について
当ソフトウェアは、ユーザーのいかなる個人情報、注文情報、店舗情報、その他のデータを収集、記録、保存、または外部のサーバーや第三者に送信することはありません。

## 2. 動作環境とデータ処理
すべてのDOM操作（注文一覧のフィルタリング、タブの追加）およびステータス判定処理は、ユーザーのローカルブラウザ環境でのみ完結します。インターネット経由での外部通信は一切行いません。

## 3. 許可（権限）の利用目的
当ソフトウェアが求める権限（BOOTH管理画面へのコンテンツスクリプト挿入）は、注文一覧ページでのUI追加および表示切り替え目的のみに使用されます。

## 4. 改定について
BOOTHの仕様変更等に伴い当ソフトウェアをアップデートする場合、本ポリシーも必要に応じて改定されることがあります。
